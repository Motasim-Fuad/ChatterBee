## Overview

**ChatterBee** is an AAC (Augmentative and Alternative Communication) app. Communicators tap symbols and phrases; the app speaks them out loud. Caregivers stay in the loop with linked accounts, board customization, visual routines, and optional real-time alerts.

Built with **Flutter**. State management uses **GetX**. Speech uses **Flutter TTS**. Paid plans (ChatterBee Pro) are handled with **RevenueCat**.

## Features

- Symbol-based communication board with categories and a core phrase row
- Text-to-speech for spoken output
- Communicator and caregiver roles, with linked accounts
- Buddy Bee child-friendly mode
- Visual routines / activity schedules
- ChatterBee Pro via RevenueCat (monthly and annual)
